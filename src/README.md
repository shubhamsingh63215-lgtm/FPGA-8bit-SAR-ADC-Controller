# Source Files

This folder contains the SystemVerilog source code for the 8-bit SAR ADC Controller.

## Files

- `sar_controller.sv` – Successive Approximation Register (SAR) control logic
- `sar_adc_top.sv` – Top-level SAR ADC module
- `sar_adc_fpga_demo_top.sv` – FPGA top module for PYNQ-Z2
- `comparator_model.sv` – Comparator model
- `dac_model.sv` – Digital-to-Analog Converter (DAC) model
- `sample_hold.sv` – Sample-and-Hold circuit model
